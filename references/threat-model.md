# 威胁模型：AI 辅助逆向能看到什么

## rea 是什么

- **形态**：一个 MCP 服务加命令行工具（npm 包 `rea-agents`），口号是 "Reverse engineer anything with agents"。安装命令会把它注册到 Claude Code、Codex、Cursor、Gemini CLI 等 agent。
- **运行位置**：在分析者自己的电脑上运行，处理他已经拿到的安装包、网页或抓包文件。原生程序借助 Hopper、Ghidra 或 IDA，Android 借助 JADX，网页借助 Chrome 浏览器。
- **产出**：带证据的分析结果。agent 据此解释某个功能如何实现，再在分析者自己的项目里写出类似实现。官方案例包括追踪 Notion 桌面端剪贴板功能从渲染进程到主进程的 IPC 链路。

## 各交付形态暴露什么

| 交付形态 | 可被提取的内容 | 对你意味着 |
| --- | --- | --- |
| 网站 | 页面结构、下发的全部脚本、网络请求与响应 | 浏览器能看到的，攻击者都能看到 |
| 前端 bundle | 模块与导入关系、路由、借助 source map 还原的源码结构 | 公开的 source map 约等于公开源码 |
| 抓包文件（HAR 等） | 请求、响应、其中暴露的字段及其在源码中的位置 | 接口多返回的字段就是泄露 |
| Electron 应用 | ASAR 内全部代码、preload 暴露的 API、IPC 通道、原生插件关系 | ASAR 只是归档格式，没有加密 |
| 原生程序 | 伪代码、汇编、字符串、符号、调用和引用关系 | 没去符号的程序等于自带注释 |
| .NET 程序集 | 元数据和 IL 指令，IL 可以反编译到接近源码 | 普通 .NET 发布物几乎等于开源 |
| Go 程序 | 编译器版本、依赖模块、构建参数 | 依赖和构建环境一览无余 |
| WebAssembly | 导入导出和可读的文本格式（WAT） | WASM 只增加阅读成本 |
| Android APK | Manifest 声明、类、反编译后的方法和引用关系 | 未混淆的 APK 接近源码 |
| 安装包、固件 | 文件清单、资源、配置、内嵌的二进制 | 打包进去的每个文件都可能被翻出来 |

## 拿不到什么

以下内容不在客户端里，任何客户端逆向工具都碰不到：

- 只在服务端运行的逻辑：算法、规则、模型、定价、风控。
- 从不下发给客户端的数据。
- 从没打包进客户端的密钥。
- 服务端对每个请求执行的鉴权和配额。

防护的主线因此是：减少客户端里值钱的东西，同时让服务端假设客户端已被完全看穿。

## 变化在哪里

- **门槛**：从会用 IDA 的专家，降到会给 agent 描述需求的人。
- **速度**：分析、解释、重写可以在一次会话里完成，复刻一个功能的时间从按周计算缩短到按小时计算。
- **压缩和改名基本失效**：大模型能根据上下文推断变量用途，单纯的 minify 几乎不构成保护。
- **规模**：同一个产品可以被很多人低成本地反复分析，"没人会花时间看我的代码"这个假设不再成立。
